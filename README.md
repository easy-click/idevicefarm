# iDeviceFarmAI操作手机

iDeviceFarm这个产品是使用AI操作手机的，基于EasyClick 技术构建，可以使用节点、VLM、OPENCV等技术识别手机屏幕，还能有离线免费的OCR来使用, 
可以用AI很多手机一起执行，如果不想写自动化脚本可以试试这个产品，完全免费，支持安卓、苹果、鸿蒙系统，可接入大模型，可用 MCP 接入 WorkBuddy 等三方软件
